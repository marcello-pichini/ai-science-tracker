# AI Science Tracker

Scientific discoveries and artificial intelligence models.

An English-language catalog of scientific results enabled by AI since 2020, with original sources, dates, evidence caveats and editorial relevance scores. A separate model catalog uses Epoch AI data and connects model families to discoveries by name. A family match does not establish which model version was used.

[Browse the site](https://marcello-pichini.github.io/ai-science-tracker/) · [Methodology](https://marcello-pichini.github.io/ai-science-tracker/methodology.html)

## Run locally

```sh
python3 -m http.server 8800 --bind 127.0.0.1
```

Open http://127.0.0.1:8800. The pages fetch JSON, so opening HTML through `file://` will not work.

## Structure

- `index.html`: discoveries, search, filters and charts.
- `models.html`: model releases and discovery links by family.
- `profile.html`: lab and model-family profiles (`?org=NAME`, `?family=ID`) with timeline, discoveries and releases.
- `methodology.html`: selection, verification and scoring criteria.
- `security.html`: separate AI-discovered vulnerability tracker; sources and remediation context in `data/vulnerabilities.json` (`docs/vulnerability-schema.md`). These cases are not included in the scientific-discovery count.
- `styles.css`: the single shared stylesheet, including the print version; fonts are hosted locally under `assets/fonts/`. Design rules: `docs/DESIGN.md`.
- `share/`, `og/`, `sitemap.xml`, `robots.txt`: generated by `scripts/generate_share.py` (see below).
- `data/discoveries.json`: curated records, documented in `docs/discovery-schema.md`.
- `data/models.json`: generated model data; do not edit manually.
- `scripts/generate_models.py`: Epoch AI import and family linking.

Discovery IDs are stable identifiers: some retain historical Italian slugs so existing links continue to work. New links use `#discovery=ID`; legacy `#scoperta=ID` links remain supported. Model family links use `models.html#fam-ID`.

## Update the data

Add or correct discoveries in `data/discoveries.json`, preserving existing IDs, source links, dates and evidence limitations. Verification means the source was checked; it does not mean the findings were independently replicated.

Download the Epoch AI notable models CSV to `work/epoch/notable_ai_models.csv`, then run:

```sh
python3 scripts/generate_models.py
python3 -m unittest discover -s tests
```

The CSV and research working files are excluded from Git. After updating the input snapshot, update its download date in the generator. Review generated family links before publishing; they are based on names, not independent attribution.

## Sharing, filters and printing

- Filters are kept in the query string: `index.html?q=&field=&org=&year=&family=&min=&sort=`. The "Copy filter link" button copies the current view.
- "Copy link" on a discovery copies `share/ID.html`, a generated full, self-canonical static discovery page with Open Graph tags and a 1200x630 card (`og/ID.png`); its full text is readable without JavaScript, with a link back to `index.html#discovery=ID`.
- After changing discoveries or the design, run `python3 scripts/generate_share.py` (add `--force` to redraw every card; it needs Google Chrome, or set `CHROME=/path/to/chrome`) and commit the generated files.
- Printing or "Save as PDF" from `index.html` produces a light, control-free list with full summaries and source URLs.

## Source context, trends and contributions

Entry details distinguish source checking from independent scientific confirmation and expose the three editorial subscores without hover. The annual chart switches between catalog-entry counts and mean editorial relevance; source composition and addition dates describe the collection, not worldwide scientific activity or review freshness.

Corrections and missing-result suggestions open public GitHub issue forms. They require GitHub sign-in, original sources and editorial review. The forms become available when `.github/ISSUE_TEMPLATE/` is published to the default branch. They never change the catalog automatically.

The shared UI helper is `assets/catalog-ui.js`. The test command also exercises its metric, disclosure and correction-link behavior using Node.js (no package installation needed).
