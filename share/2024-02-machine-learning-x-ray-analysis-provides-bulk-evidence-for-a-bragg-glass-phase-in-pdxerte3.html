Machine-learning X-ray analysis provides bulk evidence for a Bragg-glass phase in PdₓErTe₃

Researchers combined extensive X-ray diffraction with X-ray Temperature Clustering (X-TEC) to identify Bragg-glass signatures in the charge-density-wave material PdₓErTe₃. Their analysis extracted diffraction features across about 20,000 Brillouin zones and found a diverging correlation length and a phase diagram consistent with a Bragg-glass transition. The result provides bulk diffraction evidence for a phase that had been difficult to establish experimentally.

Technology: X-ray Temperature Clustering (X-TEC), a machine-learning analysis of X-ray diffraction peaks
