Anderson's 2014 commutative algebra problem resolved by Rethlas and Archon

An informal reasoning agent (Rethlas) and a formal verification agent (Archon) resolve an open problem in commutative algebra posed by D. D. Anderson in 2014, as a counterexample. The Lean 4 formalization has about 19,450 lines and was produced in roughly 80 agent hours, with the code public on GitHub. Caveat: arXiv preprint; the Lean check covers the formal statement as written.

Technology: Rethlas (informal agent) with Archon (formal Lean agent)
