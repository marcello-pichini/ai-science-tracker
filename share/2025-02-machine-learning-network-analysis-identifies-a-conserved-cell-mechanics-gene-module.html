Machine-learning network analysis identifies a conserved cell-mechanics gene module

Researchers combined transcriptomic profiles with single-cell mechanical measurements from mouse and human systems and used machine-learning-based discriminative network analysis to infer a conserved five-gene module associated with cell mechanical properties. In perturbation experiments, changing CAV1 expression by silencing or overexpression altered measured cell stiffness, providing experimental support for a selected marker’s role.

Technology: PC-corr machine-learning-based discriminative network analysis
