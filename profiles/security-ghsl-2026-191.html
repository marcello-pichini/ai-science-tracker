GHSL AI-agent index lists mutable-ref TOCTOU in MongoDB JS Kerberos release workflow

mongodb-js/kerberos release_notes GitHub Actions workflow · AI involvement attributed to GitHub Security Lab AI agent (system not named in advisory)

Finding and attribution

After maintainer authorization, the release workflow checks out a mutable pull-request ref and runs pull-request-controlled scripts with a write-scoped GITHUB_TOKEN, allowing the author to race an update into the job.

Product: mongodb-js/kerberos release_notes GitHub Actions workflow. AI system: GitHub Security Lab AI agent (system not named in advisory). Team / organization: GitHub Security Lab.

CVE identifiers: Not established in the cited evidence.

AI and human contribution (source account): GHSL’s primary AI-agent index includes this advisory in its AI-discovered list. The item advisory credits only Jaroslav Lobačevski and does not describe an agent’s role; attribution is index-level only.

Human involvement is only described where the source account establishes it; unknown involvement does not mean none. Vendor confirmation of a flaw does not confirm every claim about AI contribution.

Discovery context: The advisory documents the race and fixes; it does not claim exploitation in the wild.

Remediation status: fix documented. Fixed in PR #351 on 2026-09-03. A maintainer must trigger the workflow; branch protection may restrict writes.
