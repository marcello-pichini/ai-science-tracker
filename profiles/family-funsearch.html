Co-FunSearch finds adversarial instances raising the Best-Fit bin packing bound

A human-LLM pipeline (Co-FunSearch) finds adversarial instances for heuristics, raising the lower bound for Best-Fit bin packing in the random-order model from 1.3 to 1.5. The authors prove the 3/2 ratio analytically and report a search-found instance scoring 1.497 over 10,000 random shuffles against Packingsolver optima. Caveat: arXiv preprint; human analysis supplies the final proofs.

Technology: Co-FunSearch (FunSearch-based LLM program search)

FunSearch: new mathematical results with a language model

A language model (PaLM 2) paired with an automatic evaluator found the largest cap sets on record in some dimensions, the biggest increase in 20 years, and bin-packing heuristics using fewer bins than established methods. The problem must first be expressed as code with an evaluation procedure.

Technology: FunSearch (PaLM 2 and automatic evaluator)

Result, AI contribution and limits

Evidence context (descriptions follow the cited sources; test type is a catalog classification):

  • Publication status: Peer-reviewed paper
  • Test type: direct test
  • Tested: Programs were scored automatically by an evaluator; on the cap set problem they found larger cap sets than the best known, and on online bin packing their heuristics beat established baselines.
  • Still unknown: The abstract does not explicitly state limitations; the blog says the method needs an automatic evaluation procedure and that the bin-packing heuristics were tailored to specific data.
  • AI role: A pretrained large language model (PaLM 2) generated candidate programs in an evolutionary search guided by an automatic evaluator.
