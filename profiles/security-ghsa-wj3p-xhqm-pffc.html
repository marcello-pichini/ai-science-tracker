WAMR WASI poll_oneoff output buffer overflow

WebAssembly Micro Runtime (WAMR) · AI involvement attributed to Claude; Anthropic CVD snapshot identifies Claude Mythos Preview; the project advisory says Anthropic ran Claude Code, so the specific model/tool attribution differs by source.

Finding and attribution

WAMR’s WASI poll_oneoff path fails to validate the output buffer for all events that may be written. A guest module can cause the host runtime to write an event past the allocated buffer, crossing the Wasm linear-memory boundary into adjacent host heap memory. The Anthropic CVD snapshot records repeatable ASan overflow findings; the project advisory and later release material identify the issue and fix. The attack requires execution of a malicious Wasm module in a WAMR host. Do not infer arbitrary code execution from the documented memory corruption.
