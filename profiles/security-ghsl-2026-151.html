Taskflow Agent finds search-parameter XSS in mkdocs-material

mkdocs-material · AI involvement attributed to GitHub Security Lab Taskflow Agent

Finding and attribution

A crafted search query can reach an unescaped innerHTML write in the search-suggestion component, enabling JavaScript execution in the documentation site origin when that feature is enabled.

Product: mkdocs-material. AI system: GitHub Security Lab Taskflow Agent. Team / organization: GitHub Security Lab.

CVE identifiers: CVE-2026-73295.

AI and human contribution (source account): GHSL credits its Taskflow Agent with discovery and says Peter Stöckli manually verified the issue. The advisory says the flaw existed from v7.2.0 through v9.7.6.

Human involvement is only described where the source account establishes it; unknown involvement does not mean none. Vendor confirmation of a flaw does not confirm every claim about AI contribution.

Discovery context: The public GHSL advisory documents the XSS and remediation; it does not claim exploitation in the wild.

Remediation status: fix documented. GHSL’s timeline says the fix was released with the advisory on 2026-07-19; the GHSL public write-up is dated 2026-10-22. It describes versions through 9.7.6 as affected but does not name a fixed release number.

A source-documented fix does not establish installed patches or current safety. Source checking does not independently reproduce the finding or establish observed exploitation.

Disclosed 19 Jul 2026. AI attribution dated 22 Oct 2026. Sources checked 14 Nov 2026; these are separate dates, not a live installation check.

Recorded CVSS: Medium · highest recorded score 5.4. Documented technical effects: code execution.

CVE-2026-73295: code execution.
Prerequisites / affected scope: Material for MkDocs is a powerful documentation framework built on top of MkDocs. From 7.2.0 until 9.7.7, the mountSearchSuggest function in src/templates/assets/javascripts/components/search/suggest/index.ts contains a DOM-based cross-site scripting vulnerability in the optional search.suggest feature that allows a crafted q URL parameter to execute JavaScript in a documentation site's origin after user interaction. This issue is fixed in version 9.7.7. CWE-79: Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting').
