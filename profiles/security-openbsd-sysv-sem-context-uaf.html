OpenAI models find OpenBSD System V semaphore context-switch use-after-free

OpenBSD kernel System V semaphores · AI involvement attributed to OpenAI models (specific model not named)

Finding and attribution

A semaphore object could be freed while a thread slept in sys_semget(), leaving the resumed context with a stale pointer. OpenAI says researchers reproduced the kernel use-after-free and confirmed local privilege-escalation potential.

What to update · OpenBSD kernel System V semaphores
