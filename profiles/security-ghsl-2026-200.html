Taskflow Agent finds unsafe typed-array deserialization in seroval

seroval · AI involvement attributed to GitHub Security Lab Taskflow Agent

Finding and attribution

The JSON deserializers cast attacker-controlled typed-array buffer nodes to ArrayBuffer without a runtime check; malformed input can trigger excessive allocation/CPU use or invoke registered functions in applications using the reference registry.

Product: seroval. AI system: GitHub Security Lab Taskflow Agent. Team / organization: GitHub Security Lab.

CVE identifiers: Not established in the cited evidence.

AI and human contribution (source account): GHSL credits the Taskflow Agent with discovery and states Peter Stöckli manually verified the issue. The advisory calls it a residual variant of CVE-2026-59940 but assigns this finding its own GHSL identifier and does not list a separate CVE.

Human involvement is only described where the source account establishes it; unknown involvement does not mean none. Vendor confirmation of a flaw does not confirm every claim about AI contribution.

Discovery context: The GHSL report documents the issue and fix; it does not claim exploitation in the wild.

Remediation status: fix documented. GHSL says the maintainer fixed the issue and released seroval 1.6.4 on 2026-08-25. The advisory timeline separately says the GHSA was published 2026-09-28; the GHSL report page is dated 2026-10-22.

A source-documented fix does not establish installed patches or current safety. Source checking does not independently reproduce the finding or establish observed exploitation.

Disclosed 28 Sep 2026. AI attribution dated 22 Oct 2026. Sources checked 14 Nov 2026; these are separate dates, not a live installation check.

Recorded CVSS: Not available · no assessment established here. Documented technical effects: denial of service, other.
