Bynario AI identifies Caddy php_fastcgi authorization bypass

Caddy php_fastcgi FastCGI routing · AI involvement attributed to Bynario AI automated pipeline

Finding and attribution

When an index.php file is absent, Caddy's php_fastcgi fallback can fail to rewrite a dot-segment request. Path matchers authorize the cleaned path while the FastCGI transport executes a script named by the raw path, allowing access-control rules to be bypassed.

What to update · Caddy php_fastcgi FastCGI routing

Affected versions not confirmed in this summary.

Remediation note: Fixed in Caddy v2.11.8. The authorization bypass applies to configurations where php_fastcgi's rewrite route does not run, including the documented default when index.php is absent; the advisory describes additional configuration prerequisites for RCE escalation.
