FreeRDP shadow server accepts unauthenticated Fast-Path input before session activation

FreeRDP shadow server · AI involvement attributed to Claude (model/version not identified)

Finding and attribution

Before a shadow server reaches the authenticated active-session state, its Fast-Path input handlers forward mouse, keyboard and synchronization events to the X11 backend without the state guard used by the slow-path handlers. A network client can negotiate TLS-only RDP and send Fast-Path input before Confirm Active or valid credentials, injecting synthetic input into the host user’s X11 session. The advisory reports no screen/content disclosure or denial of service.

Product: FreeRDP shadow server. AI system: Claude (model/version not identified). Team / organization: FreeRDP maintainers / reporter.

CVE identifiers: Not established in the cited evidence.

AI and human contribution (source account): The primary FreeRDP advisory states that Claude was used to analyze source code, build the reproduction harness and draft the report. The reporter says the protocol-level reproduction was executed against an unmodified FreeRDP shadow server and independently verified. The exact Claude model/version is not identified.
