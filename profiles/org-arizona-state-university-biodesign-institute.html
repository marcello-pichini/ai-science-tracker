AI and developmental profiling reveal conserved rules for microRNA strand selection

Using a high-throughput qPCR assay, Arizona State University researchers measured microRNA 5p/3p strand use across six Caenorhabditis elegans developmental stages and selected tissues. A machine-learning model trained on experimentally measured strand usage identified compositional and structural sequence features associated with strand preference; the learned relationships predicted strand usage in other vertebrates, including humans, and the authors report that the rules are conserved but context-dependent.

Technology: Predictive machine-learning model using 77 biologically informed features, trained on high-throughput qPCR measurements from the HiTmiSS platform
