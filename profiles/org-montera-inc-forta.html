26 Sep 2023Montera, Inc. (Forta)

Gradient-boosted trees distinguish historical autism diagnostic categories

Source check: Source checked. Not independent scientific confirmation.

Finding: Gradient-boosted trees classified historical DSM-IV autism categories using assessment scores, demographics and comorbidities. In a person-separated SPARK test set, the multiclass model correctly classified 80.5% of individuals; 12.6% were assigned a different autism-spectrum category. This retrospective result does not establish screening performance under current DSM-5 criteria.

Technology: Gradient-boosted decision trees

Editorial relevance 40 medicine Published article Suggest a correction

Publication: Peer-reviewed paper · Test context: retrospective or benchmark. Catalog categories, not an evidence grade.

AI contribution
Gradient-boosted trees learned associations between clinical/assessment features and recorded diagnostic categories, then classified unseen individuals from the same retrospective dataset.
Test and result
SPARK supplied 36,965 individuals, split 80:20 without person overlap; fivefold training-only grid search optimized gradient-boosted trees. The multiclass model correctly classified 5,951 of 7,393 test individuals (80.5%), with 933 assigned a different autism-spectrum category. Separate one-versus-reference models yielded AUROCs 0.863–0.980. ABIDE supported a separately developed model, not external testing of the SPARK model.
Limitation / still unknown
Historical professional DSM-IV diagnoses were the reference; absence of diagnostic codes defined non-spectrum controls. Assessment inputs overlap with information used in diagnostic evaluation, limiting independent screening interpretation. SPARK and ABIDE models used different inputs and were fitted separately. No prospective workflow, patient benefit or current DSM-5 diagnostic validation was established; PDD-NOS positive predictive value was low.
