ENITDEFRES

Caddy rewrite can decode file path information twice and bypass path-based restrictions

Caddy HTTP rewrite module · AI involvement attributed to Anthropic OSS Scanner (model unspecified)

Finding and attribution

The rewrite handler inserted a decoded file-matcher remainder without escaping it, after which the rewritten URI was percent-decoded again. On configurations using try_files, split_path, and a rewrite with that remainder, a double-encoded path can bypass an earlier path-based deny matcher and expose static files; reserved characters can also alter the path or query. The advisory demonstrates the behavior and limits applicability to that configuration pattern.

What to update · Caddy HTTP rewrite module

Affected versions not confirmed in this summary.

Remediation note: Caddy 2.11.8 escapes the file-matcher remainder while preserving slashes before parsing the rewritten URI.
