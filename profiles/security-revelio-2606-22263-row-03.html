OpenEXR: Manifest string prefix out-of-bounds read

OpenEXR v3.4.10 · AI involvement attributed to Revelio using Claude Haiku 4.5 and Claude Sonnet 4.6

Finding and attribution

The Revelio paper identifies a out-of-bounds read in OpenEXR v3.4.10: manifest string prefix out-of-bounds read. It lists the author-assessed severity as Critical and says the finding was manually validated with a reproducible sanitizer-backed proof of vulnerability through a reachable project test harness. This is Table V item 3 of the seven-project real-world hunt.

Affected versions not confirmed in this summary.
