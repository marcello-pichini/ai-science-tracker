23 Oct 2026National University of Singapore

Shared cell ancestry inflates apparent skill in a cell-response model

Source check: Source checked. Not independent scientific confirmation.

Finding: In a retrospective audit of STATE, mean correlation on expected-null cases in one donor fell from 0.260 with reference cells sharing ancestry to 0.005 with independently sampled references, against 0.081 for a context-mean baseline. The model also fell below baseline with independent references in three additional donors. The finding concerns apparent predictive skill under the tested evaluation design.

Technology: STATE cell-response transfer model

Editorial relevance 53 biology Original sourcePaper Suggest a correction

Publication: Preprint · Test context: retrospective or benchmark. Catalog categories, not an evidence grade.

AI contribution
The trained STATE transfer model generated cell-response estimates whose accuracy could be compared against overlapping and independent reference samples.
Test and result
The audit compared reference overlap conditions, with equal reference sample sizes and the same learned predictions. The primary quantitative comparison uses one donor, with follow-up STATE comparisons across four available donors.
Limitation / still unknown
This retrospective audit characterizes the tested data and model, with expected-null cases defined operationally. It does not measure biological benefit or imply all transfer estimates are inflated.

23 Oct 2026National University of Singapore; Nanyang Technological University

Masked patch training changes visual correspondence differently at different model sizes

Source check: Source checked. Not independent scientific confirmation.

Finding: Under matched ImageNet-1K training, adding iBOT with its associated masking weakened patch correspondence in small and base Vision Transformers. Final-block patch matching improved by roughly 3.3 and 4.0 percentage points in the large and huge variants, while some local appearance details became harder to recover from deep features. These effects were measured with one training recipe.

Technology: DINO-style ViT-S/B/L/H; iBOT; fitted linear appearance probes

Editorial relevance 53 computer science Original sourcePaper Suggest a correction

Publication: Preprint · Test context: direct test. Catalog categories, not an evidence grade.

AI contribution
Vision Transformers trained with and without iBOT supplied patch embeddings for crop matching and linear appearance decoding.
Test and result
Within each scale, the comparison toggled the iBOT branch and student masking. The position diagnostic used paired local and global crops. Separate linear probes assessed appearance.
Limitation / still unknown
Data volume, loss weight, training duration and specific diagnostics limit transfer to full-scale commercial checkpoints.

19 Oct 2026National University of Singapore

Learned listening groups span country boundaries in a LastFM sample

Source check: Source checked. Not independent scientific confirmation.

Finding: A fitted spectral-plus-k-means partition of 511 LastFM users identified groups spanning seven countries. Posthoc comparisons associated the learned groups with different listening breadth, activity and artist profiles. These are descriptive patterns in a selected historical sample, not universal listener types.

Technology: Sequential BiFLICKER spectral estimation; fitted k-means unsupervised clustering

Editorial relevance 33 humanities Original source Suggest a correction

Publication: Preprint · Test context: retrospective or benchmark. Catalog categories, not an evidence grade.

AI contribution
K-means fits latent assignments in a federated spectral embedding, enabling group-specific listening comparisons.
Test and result
Seven learned groups from binary user–artist incidence; posthoc event-count summaries and leave-one-user-out intervals characterized the same sample.
Limitation / still unknown
Filtering removed low-degree users and very popular artists. Group number and genre interpretations are analysis-dependent. Breadth/artist profiles reuse clustering inputs; jackknife intervals and centralized agreement are not independent cohort validation. No causal country or preference claim.
