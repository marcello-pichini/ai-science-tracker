Unbounded handshake cache allows remote memory exhaustion

Pion DTLS · AI involvement attributed to Anthropic's OSS Scanner

Finding and attribution

The append-only handshake cache had no entry or aggregate-memory limit, retained duplicate incoming and outgoing retransmission messages for the connection lifetime, and continued accepting entries after handshake completion. Suitable traffic can exhaust application memory and cause denial of service; the separate fragment-reassembly limit did not bound this cache.
