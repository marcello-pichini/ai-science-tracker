Discourse post cooking can restore raw HTML inside a tag after sanitization

Discourse post-cooking and HTML sanitizer · AI involvement attributed to Anthropic OSS Scanner (item-specific model/version not identified)

Finding and attribution

While cooking a post, Discourse sanitized raw HTML while it was represented by a placeholder, then restored the raw HTML at the placeholder. A crafted placeholder inside a tag could therefore cause attributes to be inserted after the allow-lister had run. The project classified the fix as a security change; the reviewed primary source establishes HTML injection past the sanitizer, without stating a specific exploit outcome.

Product: Discourse post-cooking and HTML sanitizer. AI system: Anthropic OSS Scanner (item-specific model/version not identified). Team / organization: Anthropic and Discourse maintainers.

CVE identifiers: Not established in the cited evidence.

AI and human contribution (source account): The merged primary Discourse security pull request explicitly says “Discovered by Anthropic’s OSS Scanner” and identifies finding ANT-2026-ENYESJVJ. Anthropic’s OSS Scanner documentation states that findings are generated directly from its strongest models for this fast-track program; the item does not identify a specific model/version.

Human involvement is only described where the source account establishes it; unknown involvement does not mean none. Vendor confirmation of a flaw does not confirm every claim about AI contribution.

Discovery context: The project’s merged SECURITY pull request identifies a sanitizer-bypass HTML injection, directly credits Anthropic OSS Scanner, and records the fix. No CVE or GHSA appears in the reviewed primary sources, so the public PR #45728 is the case identifier. No JavaScript execution, exploitation, or zero-day claim is made.

Remediation status: fix documented. Discourse now drops any placeholder that occurs inside a tag, rechecking each substitution so hoisted raw HTML is restored only where text may appear. The change was merged in PR #45728 and backported to release 2026.10 (#45736), with related backports #45739 and #45740. Deployed patch status is not checked.
